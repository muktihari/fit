# Contributing

Thank you for your interest in improving `fit`.

We would like your help to make this project better, so we appreciate any contributions. 

Here are few guidelines to follow:

1. Please check if there is a related [issue][issues] or [pull request][pulls] before creating a new one.
1. If the fix is trivial, it's okay to submit a [pull request][pulls] directly but please do so with a proper description.
1. Or else, create an [issue][issues] first for discussion, so we have a clear understanding before submitting the changes.
1. No coding tools attributions. Never add "Generated by XXX" or any other attributions from coding tools to PRs, issues, comments, or anywhere else. We expect them to be signed off by humans, not bots.
1. Keep in mind that this project is maintained by people in their free time who come from different backgrounds and speak different languages, please be kind.

Have a nice day!

[issues]: https://github.com/muktihari/fit/issues
[pulls]: https://github.com/muktihari/fit/pulls
